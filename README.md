# Tumbler Corrected Width — downloads

Windows app for rotary laser engraving on tumblers by 8D Creations. Enter the circumference and the flat design width, and it gives the Corrected Width to engrave so the design looks round from the front.

**Download:** grab `TumblerCorrectedWidth.exe` from the [latest release](../../releases/latest). No install needed; just run it. Windows may show "Windows protected your PC" the first time; click **More info → Run anyway**.

Use the **Check for updates** button in the app to get new versions.
